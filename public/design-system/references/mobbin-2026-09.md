## 0. 先说结论：Mobbin 没有这类游戏

用户要求"找 Mobbin 上同类游戏的参考"。实测结果是否定的，且证据明确：

| 检查 | 结果 |
|---|---|
| Mobbin `Game UI` 屏分类 | `mobbin.com/explore/mobile/screens/game-ui` — 59 张截图，去重后 **27 个 app** |
| 这 27 个是谁 | Finch、Abode、KakaoBank、Kakao Pay、Duolingo、Google Arts & Culture、Deezer、NYTimes、Bloom、Noom、Duolingo Math、Kahoot!、Airtime、Brilliant、Stadium Live、Waterllama、Elevate、Khan Academy、Houseparty、HQ Trivia、Sift、Grab、Nibble、7-Eleven、Paired、Taobao、Blank Street |
| 有没有增量/放置游戏 | **一个都没有。** 这批是「游戏化产品」（教育、银行、积分、健康），Mobbin 的 `Game UI` 指的是**非游戏 app 里的游戏化界面**，不是游戏 |
| 站内检索 AdVenture Capitalist / Cookie Clicker / Melvor Idle / Egg, Inc. / Idle Miner | **0 条结果** |

**Mobbin 是产品/App 设计库，不覆盖增量游戏品类。** 硬要它给"同类游戏"参考，只能编。

它的可用价值在别处：**Mobbin 的「模式分类」和 Glyph Factory 的组件几乎一一对应**。下面记的就是这条线。

## 2. 逐屏记录

### 2.1 Duolingo · Achievements — 支撑「Aha 行缺三样信息」

来源：`mobbin.com/explore/mobile/screens/achievements-awards`（当屏标题 `Jovin` / Achievements）

看到的结构，一行一个成就：

```
[图标 LEVEL 1]   Photogenic
                 [ CLAIM REWARD ]                 ← 已达成 → 给动作

[图标 LEVEL 1]   Wildfire
                 Reach a 3 day streak             ← 达成条件写成一句人话
                 [▓▓░░░░░░░░]  1/3                ← 进度条 + 分子/分母

[图标 LEVEL 1]   Regal
                 Earn 3 crowns
                 [░░░░░░░░░░]  0/3                ← 0 进度也在同一列表里，灰条
```

**关键观察：已达成的、进行中的、0 进度的，在同一个可扫描列表里并排。** 每一行都回答"还差多少"。

Glyph Factory 的 `.aha-item` 只有 `A03 · 木 + 木 → 林` + `ACT 2`，**没有条件句、没有进度、没有分母**。这解释了为什么玩家会卡住——面板告诉他"发生过什么"，没告诉他"还差什么"。

### 2.2 Monarch · Dashboard「Getting Started」— 支撑「幕内进度不可见」

来源：`mobbin.com/explore/mobile/screens/progress`

看到的结构：一张卡，标题 + 副标题 + **分段进度条**（4 段，前 1 段填充绿色并以 ✓ 圆点收尾，后 3 段灰），下面 4 个条目，已完成的打勾且文字加删除线，未完成的是灰圆点。

**关键观察：分段进度条把"总共几步、走到第几步"压进一根 10px 高的条里**，比数字更快读懂。

Glyph Factory 的 `.act-strip` 只有篇章名 + 数值区间，**幕内进度完全不可见**。`.metric` 给的是绝对值（库存、资金），不是"离下一幕还差多少"。

### 2.3 Brightmind · 「Congrats!」— 支撑「Aha 触发缺一个时刻」

来源：`mobbin.com/explore/mobile/screens/achievements-awards`

看到的结构：**全屏**单色底 → 居中大数字 `100` + 下方胶囊 `MINUTES` → 三个进度点（✓ ○ ○）→ 底部唯一 CTA `DONE`。整屏只有一个数字、一个动作。

**关键观察：里程碑达成是一个**全屏时刻**，不是卡片里的一行小字。**

Glyph Factory 的 `.aha-focus` 是 `.game-card` 内部的一个 `<section>`，和指标格抢位置；`.ending` 全屏卡只在 A28 出现一次。中间 27 个 Aha 触发时没有对应的视觉事件。

## 3. 由参考得到的三个差距

| # | 差距 | 参考 | 提案组件 |
|---|---|---|---|
| G1 | 幕内进度不可见，玩家不知道离下一幕还差多少 | Monarch 分段进度条 | `.act-progress` |
| G2 | Aha 行没有条件句 / 进度 / 分母，玩家不知道还差什么 | Duolingo 成就行 | `.aha-row` |
| G3 | Aha 触发没有视觉时刻 | Brightmind Congrats | `.aha-burst` |

三个提案组件都已画进 `components.html`（第 13–15 节），令牌在 `tokens.css` 的**提案层**。

**重要边界：这三个组件尚未进入 `public/play.html`。** 本包只做到"设计出来并记录依据"，落地是独立变更——落地时会同时撞上隐私层（`player-privacy-v3.js` 会摘掉 `.aha-focus` 一类节点，新组件必须一并纳入剥离清单）和 28 条 Aha 的既有契约，不能顺手改。
