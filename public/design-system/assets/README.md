# assets/ — 资产来源说明

**本目录刻意为空（除本文件）。** 设计系统 v3 不依赖任何二进制资产。

## 为什么不放资产

系统的全部视觉由三样东西构成，都不需要文件：

| 视觉元素 | 实现方式 | 来源 |
|---|---|---|
| 印章「字」 | 文本 + `--font-mark`（衬线） | 系统字体栈，无字体文件 |
| 世界模型的楼房 / 天空 / 地面 | CSS 渐变 + `clip-path` | `components.html` 内的 `.world-visual` 规则 |
| 全部图标 | 无。系统不使用图标 | — |

字体同样如此：`--font-ui` 是系统 sans 栈（`system-ui` → `PingFang SC` → `Microsoft YaHei`），`--font-num` 是系统等宽栈。**没有 webfont 请求，没有许可问题，离线可用。**

这套系统刻意避免外部资产：它是印刷隐喻的系统，纸、墨、铅字都可以用纯 CSS 画出来，引入图片反而会破坏「硬边、无抗锯齿装饰」的一致性。

## 唯一的例外

`public/glyph-factory-v3-preview.webm`（v3 玩法录制，非本包资产）在 `public/` 而非本目录，因为它由 `tests/preview-v3.test.mjs` 直接引用（含 EBML 时长断言），移动它会破坏现有契约。

## 如果将来要加资产

1. 只放**本系统自己的**资产（不要放游戏素材）。
2. 每个文件在本文件里补一行：来源、许可、用途。
3. 优先 SVG，其次 PNG；不要放位图化的 UI 元素——那类东西应该继续用 CSS 画。
