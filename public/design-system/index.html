参考来源

用户要求找 Mobbin 上同类游戏的参考。实测结论：Mobbin 不覆盖增量/放置游戏品类。 Game UI 分类 59 张截图去重 27 个 app，全是 Duolingo / KakaoBank / Khan Academy 这类游戏化产品； 站内检索 AdVenture Capitalist、Cookie Clicker、Melvor Idle、Egg, Inc. 均为 0 条。 所以这里没有「同类游戏参考」——那只能编。可用的部分是它的模式分类与本系统组件一一对应， 由此得到上面 13–15 三个提案。逐屏记录见 references/mobbin-2026-09.md。

重要：本包尚未接管运行时。 public/play.html 目前仍自带一份 :root，值与本包一致但物理上是两份。 合并需要同时改 scripts/build-static.mjs（它只把白名单文件拷进 dist/， 直接 link 外部 CSS 会让发布产物掉色）。这一步是独立变更，本包不做自动迁移。
