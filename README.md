# GLYPH//FACTORY

A mobile-first, text-driven incremental web game with 2D pixel-style presentation. Inspired by the escalating systems design of classic browser incremental games, but built around an original publishing/automation theme.

## Core loop

1. Print glyphs manually.
2. Sell stock for credits.
3. Buy automation: keyboards, typists, presses.
4. Cross production thresholds to unlock new eras.
5. Future phases expand from a single desk into industrial publishing, networked language, and post-human information systems.

## Stack

- Next.js App Router + TypeScript
- CSS pixel-art scene (no heavy canvas engine)
- localStorage save for MVP
- GitHub for source / PR workflow
- Vercel for preview + production deployments

## Run

```bash
npm install
npm run dev
```

## Roadmap

- Phase 1: desk economy + meaningful pricing decisions
- Phase 2: contracts, demand, paper/ink supply, random events
- Phase 3: industrial press room and research tree
- Phase 4: digital publishing / autonomous agents
- Phase 5: language-scale endgame
