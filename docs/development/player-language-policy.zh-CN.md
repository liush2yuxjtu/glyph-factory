# 《字工厂》玩家中文语言规范

## 结论

《字工厂》的正式玩家版本必须以**简体中文作为默认语言和第一语言**。英文可以作为玩家主动选择的可选语言，但不能因为浏览器、操作系统或部署环境是英文，就让第一次进入游戏的玩家自动看到英文界面。

## 必须遵守的规则

1. **首次进入默认简体中文。**
   - 没有保存过语言偏好的玩家，进入正式玩家页面时必须看到简体中文。
   - 不使用 `navigator.language` 把英语浏览器的新玩家自动切到英文。

2. **尊重玩家主动选择。**
   - 玩家明确切换到英文后，可以保存这个偏好。
   - 玩家再次切回中文后，也必须保存中文偏好。

3. **正式玩家界面不能出现无必要的英文-only 文案。**
   - 按钮、资源名、状态、地图尺度、系统标题、日志提示等都必须有自然的中文表达。
   - 产品名、标准缩写或确有必要保留的专有名词可以保留，但不能妨碍中文玩家理解。
   - `Agent` 在中文玩家界面写作“智能体”。

4. **设计/开发术语不能泄漏给玩家。**
   - Aha 编号、Director Mode、内部预览页、版本框架等继续只属于设计和开发材料。
   - 正式玩家版本只展示当前已经发现、可理解、可操作的游戏系统。

5. **中文要求必须进入自动验证。**
   - 构建后的 `dist/play.html` 必须保持 `lang="zh-CN"`。
   - 玩家隐私/语言层必须保证新玩家默认中文。
   - 测试必须覆盖关键中文标签，避免某次重构又把 `WORLD`、`SYSTEMS`、`credits` 等英文残留带回正式玩家界面。

## 发布判定

只有同时满足下面条件，才可以把版本称为“中文正式玩家版本”：

- 新玩家默认看到简体中文；
- 核心游戏流程可以只靠中文完成；
- 手机与桌面布局都没有因为中文长度造成遮挡或横向溢出；
- 英文切换仍然可用，并且不会破坏存档和游戏进度；
- 正式玩家包不包含内部设计剧透。

## 相关文件

- `public/play.html`：玩家页面结构。
- `public/glyph-game-v3.js`：游戏 UI 与语言切换。
- `public/player-privacy-v3.js`：正式玩家边界、默认中文和玩家可见文案清理。
- `scripts/build-static.mjs`：生成正式玩家包。
- `tests/chinese-player.test.mjs`：中文默认与中文玩家界面的回归约束。
